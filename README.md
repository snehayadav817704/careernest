# CareerNest

CareerNest is a full-stack job portal platform that connects talented candidates with employers. Built using React.js, Node.js, Express.js, MongoDB, and JWT Authentication. Features include job posting, job applications, role-based dashboards, profile management, notifications, and secure authentication. The platform supports both candidates and employers with a modern responsive UI. Designed as an industry-level MERN stack project for recruitment and career growth.
